# Fake Bone Meal (Minecraft 1.21.4, Fabric) - mod TYLKO dla klienta

Dziala na KAZDYM serwerze (takze anarchia) i serwer nie musi miec moda. Wszystko jest wizualne
i widzisz to tylko Ty.

- Wybrane itemy wygladaja u Ciebie jak Bone Meal (ikona, nazwa, licznik). Prawdziwe itemy sie nie zuzywaja.
- Prawy klik zamienionym itemem w blok trawy sadzi falszywa trawe i kwiatki (tylko w Twoim kliencie,
  na serwer nie leci zaden pakiet). Gdy to zniszczysz, po prostu znika.
- **Shift + prawy klik** = normalne uzycie itemu (np. postawienie prawdziwego bloku).
- **G** otwiera menu (Itemy, Klikniecia, Teren, Wyglad).
- **H** przestawia liczby miedzy kliknieciami wedlug mapy ustawionej w GUI (przycisk `H <- #k`).
  Domyslnie zamiana parami: 1<->2, 3<->4. Klawisze mozna zmienic w Sterowanie.

## Jak zdobyc moda
Zakladka **Actions** -> ostatni przebieg -> **Artifacts** -> `fake-bone-meal-mod`.
Do gry potrzebny jest tylko Fabric Loader dla 1.21.4 (Fabric API jest wbudowane).
